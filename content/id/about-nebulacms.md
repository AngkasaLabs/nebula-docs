# Tentang NebulaCMS

NebulaCMS adalah sistem manajemen konten open source berbasis **Laravel**, dengan panel admin **React** dan frontend publik **Blade**. Arsitekturnya ditujukan untuk tim yang menginginkan stack PHP yang solid, titik ekstensi yang jelas (tema dan plugin), serta API JSON yang terdokumentasi.

## Fokus utama proyek

- **Stack terpadu**: backend, admin, dan tema berada dalam ekosistem Laravel/PHP yang konsisten.
- **Ekstensibilitas**: dukungan `hooks` (actions dan filters), template tema, serta plugin berbasis manifest.
- **Pengalaman admin modern**: antarmuka pengelolaan post, page, media, user, dan settings melalui Inertia + React.
- **Interoperabilitas**: REST API untuk konten published agar mudah diintegrasikan dengan aplikasi eksternal.

NebulaCMS tidak ditujukan untuk menyalin seluruh fitur CMS lain, melainkan menyediakan fondasi yang terkelola dengan baik, maintainable, dan ramah pengembang.

## Bahasa dokumentasi
